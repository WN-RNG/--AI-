# 光影 · 摄影项目与智能选片

面向摄影师和创作者的本地相册首版。使用 React、TypeScript、Vite、Node.js、Express、SQLite 与 Sharp；安装依赖后，本机运行不需要付费 AI 接口、云数据库或云存储。

核心流程：注册登录 → 创建项目 → 上传照片 → 查看重复、相似和疑似模糊候选 → 人工选片 → 主动发布作品。

## 本地启动

需要 **Node.js 24 或更新版本**，数据库使用 Node 自带的 `node:sqlite`。首次安装依赖需要联网。

在此目录打开终端：

```powershell
npm.cmd install
npm.cmd run dev
```

浏览器打开 <http://localhost:5173>。开发模式下，Vite 在 5173 端口提供页面，Node API 在 3001 端口运行。

首次使用请注册真实账号；默认邀请码为 `FRAME-FIRST-100`。没有预置用户名或通用登录密码。

Windows 也可以直接双击本目录的 **`启动相册.cmd`**。它会在缺少依赖时安装依赖，然后启动已经构建的页面；浏览器打开 <http://127.0.0.1:3001>。关闭启动窗口会停止本地服务，数据会保留。

如需更换邀请码，在启动前设置环境变量：

```powershell
$env:INVITE_CODE = '替换为你自己的邀请码'
npm.cmd run dev
```

注册后可自行上传照片，也可通过界面导入演示项目。导入的演示项目属于当前账号，不会代替真实上传数据。`public/demo/` 中的京都寺庙、雨巷与竹林是通过内置 imagegen 工具生成的原创演示图像，并非真实拍摄记录；完整生成提示词保存在该目录的 `prompts.json`。示例导入还会添 加重复、相似和模糊变体，方便验证筛选流程。

## 相册大图与照片预览

- 每个项目可以独立设置顶部大图：指定照片、随机轮播、顺序轮播。轮播可选择照片范围和展示间隔，也可以暂停；设置会保存到数据库。
- 点击下方照片或封面的展开按钮，进入沉浸预览。支持滚轮和双击缩放、放大后拖拽、适合屏幕、实际像素、上一张与下一张、底部缩略图切换。
- 预览中可查看真实文件信息、标记保留或淘汰、打星、设为封面、下载原图以及移入回收站。拍摄时间尚未提取时明确显示“未记录”，不会填入虚构信息。
- 键盘左右方向键切换照片，Esc 关闭预览。公开作品页为只读浏览；访问者可下载去除原始元数据的展示图，不能修改作者的项目。
- 移动端提供双列照片网格与适配的预览工具栏。系统设置“减少动态效果”时会停止自动轮播。

```powershell

```

构建后打开 <http://localhost:3001>；Node 同时提供前端页面与 API。`npm.cmd start` 之前需要先完成构建。


测试使用临时目录和程序生成的真实图片，不修改日常使用的相册数据。

## 数据与照片

默认持久化目录是项目下的 `data/`：SQLite 保存账号、会话、项目、照片信息及筛选结果；照片文件保存在本地磁盘。关闭页面或重启服务后，数据继续保留。

可以在启动前用 `DATA_DIR` 指定其他持久化目录；生产运行还支持 `PORT`、`HOST`。开发模式的 Vite 代理默认指向 3001 端口，因此开发时请保持 API 默认端口。反向代理部署时，按实际域名设置 `PUBLIC_ORIGIN`；只有在已知可信代理的环境下才启用 `TRUST_PROXY=1`。

SQLite 也支持以 BLOB 保存照片内容。此版本选择数据库管理信息、磁盘保存文件，便于预览、备份和未来迁移，同样无需购买外部存储服务。

- 支持真实的静态 JPG/JPEG、PNG 和 WebP 图片；每批最多 30 张，每张最多 20MB、8,000 万像素，任一边不超过 25,000 像素。前端会将较大的选择列表拆成多批上传。
- 原图保留；缩略图与展示图片用于页面加载。
- 文件进入回收站后可恢复。智能筛选不会自动永久删除原图。
- 备份时先停止服务，再完整备份 `data/` 目录，使数据库和照片文件保持一致。

修改默认邀请码不会改变已经创建的账号，也不会重置密码。请保管整个数据目录；删除或丢失目录会影响已有账号和照片。

## 本地智能筛选

这是一套无需付费大模型接口的本地图像分析流程：

- **完全重复**：比较文件内容哈希；重命名不会改变判断。
- **视觉相似**：使用图像感知特征，在项目内寻找相似候选。
- **疑似模糊**：根据清晰度指标给出提示，供摄影师复核。

它不提供大模型语义理解、人物识别或审美评分。裁切、明显调色、浅景深、夜景和运动题材可能影响判断；相似和模糊结果是筛选建议。分析在后台运行，界面展示处理状态，最终由用户决定保留哪些照片。

## 隐私与公开作品

项目默认私密。账号只能管理自己的项目、照片和回收站；私密照片文件及缩略图需要对应账号登录。

主动发布的项目可进入公开作品页，并通过公开链接访问。公开照片的展示文件使用去除原始元数据的展示版本；原图下载属于照片所有者的权限。撤销发布后，匿名访问相应项目与媒体将失效。已被他人下载或另存的副本无法通过撤销发布收回。

本机地址仅用于本机开发与验收。局域网访问需要配置监听地址和防火墙；面向互联网访问、域名与搜索引擎收录需要后续部署。

## 后续上线

当前交付用于本地功能验收，不承诺大规模容量、并发性能或完整生产运营能力。尚未接入短信、邮件验证、密码找回或外部备份服务。

准备上线时，应根据实际照片体积和新增量确定服务器与持久化存储，配置域名、HTTPS、访问限制、备份恢复、日志和监控，并重新检查邀请注册及公开作品规则。需要扩容时，再迁移媒体存储和数据库、拆分图像处理任务；无需为尚未发生的规模提前购买服务。
