# 首页轮播素材池

将自己选好的 JPG、PNG 或 WebP 放在本目录，按 `01-名称`、`02-名称` 命名来控制播放顺序。替换时可移走不再需要的照片；原文件不会被生成程序修改。

双击项目根目录的 **更新首页封面.cmd**，成功后刷新本地首页即可查看。正常照片会自动读取 EXIF 方向。横置但没有方向信息的照片，可在 `settings.json` 的 `images` 中按文件名设置顺时针旋转角度 `0`、`90`、`180` 或 `270`。当前五张图已经配置。

可选设置示例：

```json
{
  "images": {
    "01-example.jpg": {
      "rotation": 0,
      "focalPoint": { "x": 50, "y": 50 }
    }
  }
}
```

焦点范围为 0–100，控制全屏裁切时优先展示的位置。窄手机屏幕仍使用全屏裁切，不会把照片拉伸变形。

展示图及轮播清单输出到 `public/covers`。本目录的原文件不会复制到网站构建产物，首页没有下载或收藏入口。线上更新需提交新的展示图和清单，并重新部署。
