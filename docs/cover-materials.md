# 手动选择首页轮播照片

首页轮播只使用你放入本地素材池的照片，不联网搜图，不依赖 Python。它独立于用户的私密相册。

## 更新步骤

1. 打开项目根目录的 `cover-materials` 文件夹，放入 JPG、PNG 或 WebP。移走不再想展示的照片。
2. 按文件名前面的数字排序，例如 `01-mountain.jpg`、`02-lake.png`。最多 50 张，单张最多 30 MiB。
3. 双击根目录的 **更新首页封面.cmd**，或执行 `npm run covers:update`。
4. 成功后刷新本地首页。Render 网站需要将展示图及清单随代码提交并重新部署。

## 方向与裁切

生成程序自动读取照片的 EXIF 方向。对于没有方向标记的横置照片，在 `cover-materials/settings.json` 中设置顺时针旋转角度：`0`、`90`、`180`、`270`。当前提供的五张照片已配置方向。

`focalPoint` 可选，`x`、`y` 均为 0–100，默认 50。它决定全屏背景在屏幕比例不同的情况下优先保留哪一部分。照片按比例铺满，不拉伸。

## 文件与输出

- `cover-materials/`：你选择的原文件，生成程序只读。没有放在公共目录，不进入前端构建产物。
- `scripts/update-covers.mjs`：读取素材池、检查设置、生成展示图，最后原子替换清单。某张图片损坏时保留上一版清单。
- `scripts/prepare-cover.mjs`：校正方向、缩放至最大 2560 × 1800，生成 WebP，移除 EXIF/GPS。原文件不变。
- `public/covers/manifest.json`：首页轮播顺序和焦点设置。
- `public/covers/manual-*.webp`：网页展示图，以内容摘要命名，防止替换同名照片后缓存仍显示旧图。后续更新保留旧展示文件以兼容已打开的页面，但清单只播放本次选择的照片。

当前封面没有中部标题、底部缩略图或外部摄影平台链接。桌面端导航居中并与 Logo 同行；窄屏导航移到下一行居中，避免按钮互相遮挡。每 8 秒淡入切换，可暂停；后台、弹窗打开和系统减少动态效果时暂停。

首页不提供下载、收藏或明信片入口；浏览器展示的图像仍可被截图。相册内照片的访问与下载继续使用原有权限检查。
