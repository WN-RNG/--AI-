# B 版摄影画册与明信片

本次沿用现有 React、Express、SQLite 和相册权限，不改用户照片、账户或数据库。正常使用仍运行项目根目录的 `启动相册.cmd`；它会构建最新界面再启动。现有 Render 部署命令保持不变。

## 页面与交互

- `/`：全屏摄影封面，默认暖秋场景，三张图片每 8 秒切换。没有底部缩略图。可以暂停；浏览器切入后台、打开登录或照片预览时暂停，系统开启“减少动态效果”时不自动播放。Explore 滚动至下方公共图库。
- `/explore`：直接进入暖白公共图库。访客可以看图、看相册；上传、收藏、获准下载和明信片导出需要登录。登录后接续原操作，取消后留在浏览位置。
- `/library`：个人项目保留指定、随机及轮播封面设置，以及现有选片、上传、回收站和精选发布功能。新照片仍默认私密。
- `/favorites`：收藏的公开作品，作者撤回后不可继续查看或导出。
- EN / 中：默认英文，切换后保存在当前浏览器。用户输入的文件名、相册名称和明信片寄语不会翻译。

内页使用暖白纸色、橄榄色操作按钮、衬线标题和自然比例瀑布流。列数随窗口和浏览器缩放变化，不固定行数。

## 明信片

普通照片预览保留，新增 View / Postcard 切换。Auto 根据最多四种主色、明暗及照片比例推荐样式，不代表识别了照片语义，也不调用付费 AI。

三套模板随时可选：A Airy（清透磨砂）、B Editorial（暖纸画册）、C Cinema（深色电影）。模板仅改变新生成的明信片，原图不变。可编辑寄语、选择自动／横向／竖向、PNG／JPEG，以及最长边 2400 或 3600 像素。照片完整放入圆角画框，模糊只作用于背景。

生成在浏览器中进行。预览读取展示图，导出时重新请求受保护的下载接口：作者可用自己的照片，其他用户仅能导出作者明确允许下载的展示图。作者关闭下载后，即使旧预览仍打开，服务器也会拒绝导出。不会编造相机、镜头、快门或地点等缺失参数。

## 首页素材

`public/covers/fallback-manifest.json` 配套三张原创 AI 风景示意图（暖秋、雪山、海岸），不标为 500px 作品。生成方式与提示说明保存在 `public/covers/asset-prompts.json`。

首页素材独立于用户图库，没有下载、收藏或明信片入口。图片展示到浏览器后无法彻底防止截图或浏览器取图。

真实摄影作品的替换方法见 [首页轮播素材导入](cover-materials.md)。已提供 500px 可见页面采集与同步程序，保留默认三套封面并加入实际展示图，也支持直接导入授权文件或 HTTPS 图片地址。程序无需在 Render 常驻运行。

项目内已配置 Python 3.14.10 与独立虚拟环境，Python 导入和同步测试已经运行。后端直接读取首页封面素材，更新成功后刷新首页即可查看。
