# 明信片与手机界面

## 本轮可直接使用

打开一张照片，切换到 **Postcard / 明信片**。默认使用沉浸磨砂样式，提供精选英文祝福、换一句和手动编辑。成品只保留照片与手写祝福，不再写入文件名、作者、相机参数或导出尺寸；这些信息仍可在普通看图的信息面板中查看。

明信片支持跟随照片、横向、竖向三种方向，以及 PNG / JPEG、2400 / 3600 像素最长边。更换手机界面不会强制裁切照片或改变导出方向。私密照片仅作者可导出；公开照片仍需作者开放下载，浏览者登录后才可导出，服务器会再次检查许可。游客登录会接续此前的导出设置。

**水彩艺术暂未开放**，界面已明确标注“待接入”。真实水彩需要另行配置图像模型，本轮不上传照片到外部 AI 服务，也不产生 AI 调用费用。

## 磨砂图片如何生成

1. 浏览器加载有浏览权限的展示图，将其缩小至 64 × 64 像素采样。
2. 使用确定性的聚类提取最多四种主要颜色，绘制柔和渐变并模糊背景层。
3. 在背景上居中绘制清晰、保持完整比例的照片，添加窄圆角边缘和轻阴影。
4. 等待本地 Allura 手写字体加载，绘制精选或用户编辑的英文祝福。
5. 导出时通过受权限控制的下载接口重新获取图片，在浏览器 Canvas 中生成 PNG 或 JPEG。背景模糊不会应用到照片主体，原文件不被修改。

这是本地图片合成，不是生成式 AI。展示预览和最终导出使用相同排版算法，导出按所选尺寸重新绘制。

## 字体

- 照片卡片的名称和日期使用用户提供的 **Adobe Caslon Pro Regular / Italic**，在代码中注册为 `Album Caslon`。
- 明信片祝福使用免费 **Allura**，注册为 `Album Blessing`。其 OFL 许可证与字体一并存放。
- 字体均位于 `public/fonts/`，随项目部署，不依赖电脑已安装字体或国外字体 CDN。中文继续使用中文字体回退。

## 手机与电脑共用同一产品

- 电脑保留侧栏与暖白瀑布流；手机使用紧凑页头和公共图库、我的相册、我的收藏三个底部入口。首页摄影首屏和弹窗、看图流程内不显示底部导航。
- 手机通常显示双列瀑布流，极窄屏切为单列；图片保持自然长宽比。个人相册封面根据内容增高，避免文字和操作互相遮挡。
- 手机普通看图支持滑动换图、双指缩放和放大后拖动；照片信息以底部面板展开。电脑仍使用信息侧栏。
- 手机明信片编辑采用上方预览、下方设置的纵向布局，导出按钮保持在滚动区底部可操作位置。表单字号、触摸区域和屏幕安全区一并适配。

## 相关代码

- `src/postcard.ts`：配色、完整比例排版、Canvas 合成与受权限控制的导出请求。
- `src/postcardBlessings.ts`：英文祝福库与换句逻辑。
- `src/components/PostcardMaker.tsx` / `.css`：编辑与导出界面。
- `src/components/PhotoPreview.tsx` / `.css`：普通看图、触摸手势与照片信息。
- `src/components/MobileNavigation.tsx`、`src/mobile.css`：手机导航与相册、表单的响应式布局。
- `src/fonts.css`、`src/fontLoading.ts`、`public/fonts/`：实际字体资源及 Canvas 字体加载检查。
