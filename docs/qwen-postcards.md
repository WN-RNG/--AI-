# Qwen 明信片与上传优化

## 启用真实出图

本项目调用千问 AI 平台的按量付费图像接口，不需要 GPT 或 DeepSeek 密钥。管理员在 Render 的服务页面进入 **Environment**，添加以下环境变量，保存后部署：

| 变量 | 内容 |
| --- | --- |
| `DASHSCOPE_API_KEY` | 千问平台创建的按量付费 API Key，只保存在后端 |
| `QWEN_BASE_URL` | `https://maas.qianwenaiapi.com/compatible-mode/v1` |
| `QWEN_IMAGE_MODEL` | `qwen-image-2.1-turbo` |
| `QWEN_MONTHLY_BUDGET_CNY` | `50`，可调低 |
| `QWEN_RESERVE_PER_IMAGE_CNY` | `0.60`，每次生成保守预留金额，可按实际模型费用调高 |

本地使用时，将根目录 `.env.example` 复制为 `.env`，自行填写密钥，再使用原启动文件启动。Node 24 自动读取该文件；已有进程环境变量优先。`.env` 已被 Git 忽略。不要将密钥放入前端代码、`VITE_*` 变量、聊天或 GitHub。

这里使用截图中的千问 AI 平台域名。它与旧版百炼的区域端点是不同配置，不应混用其他平台的密钥。官方接口：`POST /images/generations`，请求包含模型、指令、参考图 Base64、尺寸和一张输出；不使用 multipart `/images/edits`。

依据：[图像编辑](https://platform.qianwenai.com/docs/developer-guides/image-generation/image-editing)、[API Key](https://platform.qianwenai.com/docs/api-reference/preparation/api-key)。

## 用户操作

打开照片，切换 Postcard。磨砂模式仍可免费本地合成；如需 AI 柔雾自然光影背景或水彩转绘，先登录，勾选发送缩小照片副本的许可，再点击生成。

- 摄影款：参考照片仅用于背景配色与光影生成，主照片由浏览器原样叠加。
- 水彩款：Qwen 将照片副本转绘为真正的水彩画，再由浏览器加上英文手写祝福。人物与建筑细节可能变化，原文件始终保留。
- 生成结果保存于私有数据目录。重新打开同一照片和样式时复用已有任务，不自动再次付费生成。
- 未配置密钥时显示配置提示；不会用普通滤镜伪装水彩。
- 通常以约两分钟作为等待预期，不保证时限。单次后端最长等待三分钟。超时、未知失败或服务重启后，不自动重新提交，以防重复计费；需管理员核对任务和平台用量。
- AI 制作与结果下载均检查照片当前权限。非作者需作者允许下载；撤回公开、下载许可或删除照片后，相关结果不可继续读取。

## 预算与数据保存

`postcard_jobs` 表记录任务与预算预留，账期按 UTC 月份累计。默认每次预留 0.60 元，50 元允许最多约 83 次新生成；这是保守的调用控制，不是收费报价。未知失败或中断的任务保留预留金额，避免未知账单导致超额；明确被服务拒绝的 400/401/403/404/422 请求释放预留，配置修正后允许用户主动重试。平台实际账单以其模型价格与调用记录为准。

**预算控制依赖数据目录持续保存。** Render Free 的本地磁盘是临时存储，休眠、重启或重新部署可能丢失数据库、生成图片和预算记录。此配置不能保证该环境下跨重建的月度硬限额。试用时应配合平台账户的用量/余额控制，并及时导出成品；长期运行应将数据库和文件迁移到持久化存储。不要以临时结果 URL 代替长期存储。

## 性能改动和实际边界

- 原始文件字节保持不变；前端最多两个批次同时传输，大文件仍需本次确认。
- 上传请求优先生成缩略图并保存原图，高清预览进入数据库任务队列。新照片可先使用缩略图，高清版本就绪后后续读取会自动使用它。
- 原图校验、编码、分析和 AI 参考图处理仍共用受限图像任务通道，避免小内存实例被并发解码耗尽。
- 高清预览任务重启后可继续处理；失败的文件保持缩略图回退。
- 上传进度按文件字节汇总，服务器校验与缩略图处理单独提示。
- 首次打开私人空间合并相册列表与默认相册数据请求；相册统计改为 SQL 聚合。照片首屏渲染 48 张，点击加载更多继续显示。接口仍获取当前相册照片数据，以保留现有全相册搜索、筛选、选片与封面逻辑；这不是后端游标分页。
- Render Free 空闲后的平台唤醒、跨境网络传输速度无法凭以上代码消除，不能保证 75MB 上传降到固定秒数。

自动测试使用独立临时数据库、真实编码照片和模拟 Qwen 响应，覆盖权限、同意、预算、重复请求、重启复用、撤回许可和原图字节校验。模拟服务只能验证接口流程；真实水彩质量、延迟和账户权限需配置真实密钥后实测。
