# Album typography

## Gallery captions

`ACaslonPro-Regular.otf` and `ACaslonPro-Italic.otf` are the user-supplied Adobe
Caslon Pro font files. Their original internal family is **Adobe Caslon Pro**;
the application uses the CSS alias **Album Caslon**. Only the two faces used for
photo filenames and dates are included. The font files have not been modified.

## Postcard blessings

`Allura-Regular.ttf` is **Allura**, designed by Robert Leuschke, obtained from
the official [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/allura).
The application uses the CSS alias **Album Blessing**. This font is distributed
under the SIL Open Font License 1.1; its full license and copyright notice are
included in `Allura-OFL.txt`. The font file has not been modified.

The application serves these assets locally. Visitors do not need the fonts
installed on their device, and the page makes no external font service request.
